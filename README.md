"# SkillBridge-Academy-Training-Website" 
SkillBridge IT Training Website

A modern, responsive UI project designed for an IT training institute.  
This project showcases a professional landing page with clean design, smooth layout, and mobile-first responsiveness.

---

## 🌟 Features

- ✅ Fully Responsive Design (Mobile, Tablet, Desktop)
- ✅ Modern UI with Gradient & Glassmorphism Effects
- ✅ Sticky Navigation Bar
- ✅ Interactive Hamburger Menu
- ✅ Course Cards Section
- ✅ About & Why Choose Us Sections
- ✅ Student Testimonials Slider
- ✅ Contact Section with Social Links
- ✅ Clean and Structured Code

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox + Grid)
- JavaScript (Vanilla JS)

---

## 📱 Responsive Design

This project is optimized for:

- 📱 Mobile Devices
- 📲 Tablets
- 💻 Desktops

Media Queries used:
- max-width: 768px (Mobile)
- 768px – 1024px (Tablet)
